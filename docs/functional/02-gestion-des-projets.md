Principe de séparation Projet / Finance
Module Projet

Le module Projet représente la vision contractuelle et opérationnelle du chantier.

Il contient les informations qui peuvent être partagées avec les acteurs du projet, selon leurs droits :

identité du projet ;
intervenants ;
localisation ;
planning ;
charge vendue ;
montants contractuels (devis, commande, avenants) ;
documents ;
réunions ;
risques ;
réserves ;
suivi d'avancement.

Ces informations correspondent à ce qui est connu ou peut être communiqué au maître d'ouvrage.

Module Finance

Le module Finance représente la vision interne de l'entreprise.

Il contient exclusivement les informations relatives au pilotage économique :

coûts horaires ;
prix de revient ;
achats ;
sous-traitance ;
budgets détaillés ;
marges ;
écarts ;
rentabilité.

Ces données sont réservées aux profils habilités.
