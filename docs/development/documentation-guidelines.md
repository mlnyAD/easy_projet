

## Nos règles de rédaction

- Un document = un sujet.
- Une information = un seul document (source unique de vérité).
- Les documents se lisent dans un ordre logique.
- Chaque document commence par une vision d'ensemble.
- Un schéma précède les explications lorsqu'il apporte une meilleure compréhension.
- Un schéma = une idée.
- Les schémas vont du général vers le particulier.
- Le texte est concis, concret et sans répétition.
- Chaque document doit pouvoir être lu en une seule fois.
- Les renvois servent à approfondir, jamais à comprendre le document.
